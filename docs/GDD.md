⚔️ Кости и Пепел (рабочее название)
Game Design Document — v1.0 (утверждён)
Дарк-фэнтези выживание · свой движок (C++20 / SDL3 / OpenGL 3.3) · solo · бюджет 0

1. Ядро
   1.1 Питч
   Жестокая несправедливая игра о выживании в враждебном мире:собирательство, крафт и борьба за ресурсы, где можно потратить уймувремени — и не получить ничего.

Жанр: action-RPG / выживание / исследование
Камера: 3D-изометрия 45°
Протагонист: одиночка, «оказался не в том месте не в то время»
Референсы: Dark Souls (ощущение боя), The Forest (крафт/выживание),Pacific Drive (исследование+сбор), The Long Dark (одиночество)
1.2 Эмоциональный профиль (якорь каждого дизайн-решения)
Эмоция Роль
Беспомощность почти всегда: мир сильнее игрока
Любопытство / исследование главный магнит движения
Тяжесть и методичность темп всего
Злость / утрата / отвращение точечные акценты (смерть, находки, декор)
Тест каждого решения: «усиливает ли это одиночество, исследованиеили тяжесть?» Если нет — вырезаем.

1.3 Фишки
Карта рисуется игроком вручную (карта = игровые объекты)
Прогрессия через использование умений (нет стат-поинтов)
Фиксированный мир + рандомный лут (Long Dark-модель)
Бартер вместо валюты; каждая зона = раса врагов + торговец той же расы
Весь контент-фон — собственный ML-конвейер ассетов
1.4 Цели проекта
Сделать игру-организм целиком: дизайн, движок, ассеты — свои.Обучение геймдеву. Монетизация — не цель срезки.

2. Мир
   2.1 Иерархия
   КАРТА (рисуется игроком)└─ ЛОКАЦИЯ «Выжженный лес» (MVP) ├─ ЗОНА «Деревня Начало» — хаб, безопасна ├─ ЗОНА «Лесные угодья» — открытая, нежить ├─ ЗОНА «Подземелье» — 5–8 комнат └─ ЗОНА «Шахты» — за коротким переходом (мин. контент в MVP)└─ ЛОКАЦИЯ 2+ — TBD (соединены переходами между локациями)
   2.2 Переходы
   Тип Доступ Функция
   Длинные открыты всегда свобода маршрута; зоны НЕ балансируются под игрока (несправедливость — фича)
   Короткие открываются действием (ключ/рычаг/расчистка/убийство сторожа) прогрессия поступками; причина закрытости всегда видима
   2.3 Зоны MVP «Выжженного леса»
   Зона Роль Враги Торговец
   Деревня Начало хаб: 3 целых дома (сон/сейв), 4 руин, хранилище нет скелет-торговец (бартер: кости)
   Лесные угодья сбор, патрули, вход в подземелье скелеты ×3 типа нет
   Подземелье испытание, награда нежить нет
   Шахты за коротким переходом; 2–3 комнаты, 1 новый враг, 1–2 награды TBD TBD
   2.4 Жители и враги
   Дружелюбных NPC нет — только торговцы; всё остальное враждебно
   Враги MVP (нежить): скелет-мечник · скелет-лучник · скелет-тяжёлый
   ИИ: конечный автомат (патруль → агр → атака → возврат), конус зрения,слух от бега
   Дроп: кости 100% (валюта бартера) + шанс предметов из пула
   2.5 Расы и зоны (пост-MVP)
   Зона = раса врагов = раса торговца = свои товары (шахты — шахтёрскаяраса: руда/инструменты). Расширение мира = новая зона-экосистема.

3. Геймплейный цикл
   Деревня (сон=сейв, бартер) → длинный переход → Угодья→ лут(рандом)/бой → короткий переход (открыть действием!) → Шахты→ ... → возврат → сон → бартер → дальше
   Мир постоянен: зоны не регенерируются, убитые враги остаются мёртвыми
   Смерть: возрождение в Деревне; потеря всего ненадетого; экипировкаостаётся
   Сохранение: автосейв по вехам (переход, сон, убийство «мини-босса»)
4. Выживание (HUD: один угол)
   Полоса Тратится Истощение Восстановление
   HP урон, голод смерть сон, еда
   Стамина бег, удары нельзя бить/бежать время, еда
   Голод время HP тает, стамина↓ еда
   Сон время стамина-реген↓, (галлюцинации TBD) сон в целых домах
   Рассудок тьма, мертвецы (эффекты TBD — заглушка в MVP) огонь, день, предметы
5. Бой
   Реальное время; атака в направлении курсора
   Лёгкий (ЛКМ) / тяжёлый (ПКМ) удар; промах тоже тратит стамину
   Слоты: 2 руки + сумка (крафт) + 2 кольца + амулет (пассивки, пост-MVP)
   Блок/уклон/пари — НЕТ в MVP (осознанно)
6. Инвентарь, крафт, лут
   Инвентарь: grid-сетка; экипировка: 2 руки, сумка, кольца, амулет
   Крафт: рецепты ТОЛЬКО из найденных книг умений
   Лут — фиксированный мир + рандомное наполнение (Long Dark)
   Источник Рандом
   Карта, зоны, переходы, враги, точки лута hand-crafted ❌
   Наполнение точек лута пулы+веса, сид прохождения ✅
   Дроп врагов пулы+веса ✅
   Критические предметы (ключи, книги) hand-crafted ❌ НИКОГДА
   Точки лута: категория (контейнер/тайник/труп), пул зоны, 1–4 ролла,шанс пусто 20–40% (разочарование — часть тона), редкость весами(60/30/9/1). Точка обыскана = пуста навсегда. Гарантии жалости (вес едырастёт при голоде) — TBD баланс.

Экономика: выживание — рандомный лут; развитие — стабильные кости →бартер. Две линии, рандом не съедает прогресс.

7. Сон и дома
   3 целых дома: сон = сейв-веха + восстановление
   4 руин: частичное укрытие (разборка на ресурсы — пост-MVP)
   Деревня в MVP абсолютно безопасна (набеги — пост-MVP идея)
8. Нарратив
   Пролог (текст при первом запуске) + записки по миру
   Через структуру: длинные переходы = дороги былой жизни;короткие = мини-истории «почему закрыто»
   Единый сюжет — TBD после проработки лора
9. Технологии
   Движок: свой. C++20 · SDL3 · OpenGL 3.3 core · cgltf · stb_image · glm · CMake+vcpkg(manifest)
   Ассеты: GLB (glTF 2.0) из собственного ML-конвейера asset-forge(LoRA gprop_v2 → Hunyuan3D-2mini → Blender headless)
   Звук: miniaudio; амбиент+SFX из free-паков; музыку не пишем
   Платформа: Windows-only; мультиплеер — никогда; сейвы: JSON
10. Ограничения (жёстко)
    Бюджет 0₽ · музыку не пишем · анимации — минимум/заглушки ·никакого онлайна · мир не регенерируется · 5–10 ч/нед, дедлайна нет

11. MVP «Деревня + Подземелье»
    IN (16 пунктов):

Зона Деревня: 3+4 дома, торговец, хранилище
Зона Угодья: сбор, патрули
Зона Подземелье: 5–8 комнат
Зона Шахты: мин. наполнение за коротким переходом
Переходы: длинные ×2–3 + короткий ×1 (действие)
Протагонист: ходьба/бег (стамина), изометрия
Бой: лёгк/тяж по курсору, HP/стамина
Скелеты ×3 типа, ФСМ
Инвентарь grid, 5–10 предметов, экипировка рук
Бартер (кости → 5–6 предметов)
Сон = сейв + восстановление
Голод (упрощённо)
Крафт: 1–2 рецепта из книги (сумка, факел)
Пролог + 2–3 записки
Карта: закрашивание пройденного
Автосейв-вехи; амбиент + 3 SFX
OUT (осознанно): рассудок-эффекты, эссенция/статы, кольца/амулеты,броня-слоты, сложный ИИ, богатые анимации, набеги, погода, музыка,вторая локация, перезаполняемый лут

Критерий готовности: незнакомец: пролог → деревня → лес → открываеткороткий переход → Шахты (больно!) → возврат, сон, бартер → «хочу дальше».

12. Движок — этапы (MVP-план)
    Этап Результат Оценка (вечера)
    0 окно+цикл+ввод (SDL3), CMake 2–3
    1 шейдеры, текстуры, камера-изо 3–4
    2 GLB-лоадер (cgltf) — ассеты фабрики в сцене 3–4
    3 мир-сцена: тайлы земли, спавн пропсов, свет+туман 3–4
    4 протагонист: ходьба, стамина, AABB 2–3
    5 бой: лёгк/тяж по курсору, хитбоксы, манекен 3–4
    6 скелеты ×3, ФСМ, дроп-кости 4–5
    7 инвентарь grid, точки лута+сид 3–4
    8 бартер UI, сон=сейв 3–4
    9 пролог, записки, HUD, звук 4+
    Итого MVP: ~25–35 вечеров. Правило: каждые 2–3 этапа — играбельныйбилд; рендер дописывается только когда игре не хватает конкретнойфичи.
